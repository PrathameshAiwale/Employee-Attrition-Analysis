# Employee Attrition Analysis Dashboard | Power BI

## 📌 Project Overview
This project analyzes employee attrition trends using the IBM HR Analytics dataset. The goal is to help HR teams understand factors influencing employee turnover and improve retention strategies using data-driven insights.

## 🎯 Objectives
- Identify which departments and job roles have the highest attrition.
- Explore how factors like overtime, salary, age, and job satisfaction impact attrition.
- Build an interactive dashboard to help HR make informed decisions.

## 🛠️ Tools & Technologies
- Power BI (Visualizations, DAX, KPIs)
- Microsoft Excel (Initial data cleaning)
- Dataset Source: IBM HR Analytics Dataset ([Kaggle](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset))

## 📊 Key Metrics & Visuals
- **KPIs**: Total Employees, Attrition Rate, Avg. Monthly Income, Avg. Job Satisfaction
- **Bar Charts**: Attrition by Department, Job Role, Education Field
- **Pie/Donut Charts**: Attrition by Gender, Marital Status
- **Scatter Plots**: Monthly Income vs Job Satisfaction
- **Slicers**: Department, Job Role, Gender, Overtime, Marital Status
